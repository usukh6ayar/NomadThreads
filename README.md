# 👘 NomadThreads

Mobile e-commerce app for the traditional Mongolian deel.
Монгол дээлийн онлайн дэлгүүрийн мобайл апп.

![NomadThreads](docs/cover.png)

## What it does
- Browse deels, khurems and boots by category and brand
- Search, product pages and a shop view
- Store locations on a map
- Sign-in, settings and localized text
